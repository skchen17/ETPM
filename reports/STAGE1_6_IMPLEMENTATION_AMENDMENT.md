# Stage 1.6 pre-formal implementation audit

The frozen gate thresholds, architecture, memory law, task generator, optimizer and training data were not changed. The first 24 development cells used a component-lesion diagnostic applied at the final bridge. That diagnostic can miss information already copied from F/M into H during post-scrub distractors. Before any formal cell, lesion evaluation was corrected to zero only the selected F or M component immediately **after H scrub**, leaving H and the other component intact. This is the intended finite memory-necessity intervention under the frozen protocol's “before bridge” wording.

Development LR selection uses only held-out unlesioned CE in each arm, which is invariant to the lesion diagnostic. All first-pass development artifacts are retained unmodified. Formal gate G36 and all formal checkpoint lesions use the corrected scrub-boundary intervention. Neither threshold nor outcome was seen when making this correction; no formal run had started.

The Stage 1.6 exact-objective training-length experiment is on the new H-scrub composed world. It establishes whether this operator learns memory dependence with longer training under a memory-necessary objective, but cannot by itself prove that the frozen Stage 1.5 original four-family objective was merely undertrained. Final interpretation must keep this distinction explicit.
