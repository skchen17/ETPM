# Stage 2D.4 Protocol — Action-Conditioned Persistent Memory Access

This stage asks whether candidate-conditioned queries make conditional behavioral memory easier to learn while preserving the frozen ET-RCM memory law.

The formal arms are A0 legacy, A1 action-conditioned F/M queries, A2 action-conditioned gate only, A3 parameter-matched downstream capacity, and A4 legacy plus the frozen 50-step Stage 2D.3 C1 warmup. A0–A3 train only on observed consequences. Candidate branches are read-only and never write or advance persistent state.

Primary stabilization requires A1 to reach at least 6/8 healthy independent runs and exceed A0. Expanded replication and downstream dynamics experiments are conditionally authorized only by their declared gates. External write, readout-conserving consolidation, decay, NULL and SELF_OUTPUT laws remain frozen throughout.
