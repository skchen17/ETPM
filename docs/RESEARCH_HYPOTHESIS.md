# Research hypothesis

> **Can a model with its own internal time transform transient experience into persistent computational state through repeated internal use, while keeping self-repetition from becoming new evidence?**
>
> **一个具有自身内部时间的模型，能否让短暂经历因为后续内部计算中的反复使用而自然转化为持久计算状态，同时避免把自己的重复思考误当成新的证据？**

## Hypotheses

- **H1 — content:** only an external event may create a new associative target.
- **H2 — lifetime:** repeated internal access may transfer an existing fast
  trace into slow state.
- **H3 — no self-evidence:** transfer must conserve `F+M` before decay.
- **H4 — utility:** traces repeatedly used by future computation should outlive
  otherwise matched traces.
- **H5 — endogenous time:** `Phi(S, 0)` may advance reasoning, organization, or
  consolidation without inventing an external fact.

The nine-toy protocol and B0–B6 baselines are frozen in code and configuration.
Positive, null, and negative results are retained. Stage 2 is gated by G1–G6;
none of these hypotheses is treated as established merely because the code
implements it.
