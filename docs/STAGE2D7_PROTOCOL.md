# Stage 2D.7 frozen-evaluator compatibility protocol

Research question: does the protected evaluator fail to read useful history information already present in the candidate H representation? Stage 2D.7 is additive. Stage 2C–2D.6 checkpoints, reports, results and code are read-only references. F write, F→M transfer, gamma=.50, rho_F=.97, rho_M=.9995, query, recurrence, action embedding, SiLU, downstream output head and observed-only loss are unchanged in the diagnostic phase.

## Cohorts and independent unit

The independent statistical unit is one trained model. Historical legacy C0: the 24 Stage 2D.3 checkpoints, including the eight frozen primary healthy and eight frozen primary shortcut runs listed in `results/stage2d6/processed/frozen_rule.json`. Independent Stage 2D.6 C0: 24 checkpoints. New Stage 2D.7 C0: init seeds 24101–24108 × stream seeds 25101–25103, eval seed 26601, exactly the Stage 2D.3 C0 recipe and checkpoints at 0/25/50/100/200/300/500/750/1000/1500. No outcome-based additions to this cohort. Healthy means TV≥.10, |IHA|≥.10, |BS|≥.10 and CFA>0. Strict F2 means nonhealthy, max(H,M z-probe)≥.75 and |BS|<.10; F1 means nonhealthy with max(H,M z-probe)<.75.

## Projection and finite intervention

The exact candidate path is pooled temporary H → frozen first-layer state weights W_H → addition of action projection and bias → SiLU → frozen final output layer. The 2×2 history/action cells are averaged within a run before any statistic. D_H is the action-averaged history contrast at `evaluator_H_input`; D_S is its contrast at `fusion_H_projection`; G_proj=D_S/(D_H+epsilon). SVD is of the checkpoint's actual W_H. Report rank, top/bottom k=1/2/4/8/16 unweighted energy and V_H=G_proj². Verify the matrix equality and per-action hook at numerical precision. Full rank is never called a nullspace.

The state-main restoration uses the eight frozen historical healthy runs for an average *logit-interaction* template and median healthy state-main norm. For each target failed run, the target's local four-output-by-state-projection Jacobian adjoint maps that template into its own coordinates. The resulting vector is normalized to the healthy median (1.00×, below the 1.25× cap); the same vector enters both action cells for history A with +δ/2 and history B with −δ/2. No factorial interaction is inserted at this node. λ=.25/.5/1 are recorded; λ=1 is the frozen gate. Matched controls: seeded random state direction, lowest-sensitivity response direction, action-main pattern and common shift. The fusion-post direct interaction injection is a separate positive ceiling, not evidence for the state-projection hypothesis. G125 requires TV/IHA/|BS|≥.10, IHA and |BS| gains≥.025, post-fusion interaction gain≥.025, superiority≥.025 on IHA and |BS| over each negative control, exact node action/interaction preservation and cap compliance in ≥6/8 failed checkpoints.

For healthy necessity, each checkpoint's own W_H history state contrast is scaled by β∈{0,.25,.5,.75,1} around its midpoint. β=0 exactly removes it without changing action main or factorial interaction at the hook. Controls are a common shift and an *equal-norm action-pattern perturbation* (not deletion of native action signal). G126 requires post-I≤.75×native, IHA≤.5×native, |BS|≤.5×native, negative-control margins≥.025 and exact hook preservation in ≥6/8 healthy checkpoints.

The H-space rotation is conditional on support for both G123 and G124. If triggered, spherical interpolation preserves the history-contrast norm and common midpoint; high- and low-gain W_H singular subspaces and random rotations are compared. It is not run merely because a single descriptive SVD pattern looks promising.

## Frozen-upstream refit ceiling

R0 is the original checkpoint. R1 trains only W_H and b_H (1056 parameters); R2 only W_A (256); R3 only the 32 fusion biases; R4 a 1056-parameter dense residual adapter *after* SiLU. All upstream, query, memory, action embedding and final output weights remain exact. Frozen-upstream features are generated on 200 reset episodes, batch 16, length cycle 4/6/8, from legal observed fields alone; no latent z, correct-action or memory labels enter features or targets. Each arm receives the same 500 AdamW updates, batch 256, lr=.001, weight decay zero. Training seed 37101 uses train-parity surfaces; held-out eval uses each checkpoint's independent eval seed and novel-parity surfaces. Gate G128 requires R1 healthy on ≥6/8 failed models, with IHA and |BS| ≥.025 above R0 and every R2/R3/R4 control.

## Conditional training rescue

Only ≥2 supported G125/G126/G127/G128 may authorize this branch. C0 is original all-protected legacy. C1 adapts W_H,b_H at {.01,.1,.25}×upstream LR. C2 adapts the same coordinates through T_w∈{100,300,500} then freezes them. C3 is zero-effect-initialized H→H low-rank residual, ranks 2/4; W_H remains frozen. C4 is an equally parameterized generic residual after SiLU (ranks 2/4); a dense 1056-parameter C4 also matches C1/C2's W_H+b_H count. C5 adapts only W_A. Each development configuration uses the same two seed pairs (26101,27101) and (26102,27102), eval 28601. The selection rule is frozen before all development outcomes: choose a 2/2 healthy state-specific configuration by simplest order C1→C2→C3; if none, choose a 1/2 configuration by healthy count, then mean IHA, mean |BS| and simplicity; if none, stop. No per-seed hyperparameters. Formal seeds are eight new pairs (29101–29108,30101–30108), eval 31601, for selected/C0/C4/C5. Expanded crossing is conditional on G130.

All rescue arms use exactly the original observed consequence cross-entropy plus original 0.001 H penalty. No paired warmup, behavioral separation loss or oracle side signal is added. Every run saves the frozen protocol, checkpoint sequence and provenance.

## Pre-outcome protocol corrections

Two control implementations were corrected before gate adjudication: an early healthy action control deleted the native action effect, which was not a matched perturbation; it was replaced with equal-norm action-pattern perturbation. An early fusion-post positive ceiling used the target's native interaction direction and could miss the healthy output sign; it was replaced with healthy output-template alignment through the frozen final linear map. All 48 preexisting-cohort endpoint audits were rerun under the corrected controls. The preliminary logs are retained. Before full development evaluation, the dense C4 control was added to match the 1056 parameters of C1/C2; it does not alter any rescue arm or selection rule.
